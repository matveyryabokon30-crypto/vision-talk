# Новая основа Pablicus

Локальный интерактивный прототип: Чаты / Дела / Боты / Вы, боковой выбор представления, обычный ввод фиксированной высоты, поиск, локальные заметки и дела, сохранение черновика, светлая/тёмная тема. Демонстрационные данные отделены от установленного приложения. Боты показывают роль; генерация, загрузка файлов и production transport ещё не подключены.

Из корня репозитория:

```sh
python3 prototypes/pablicus-next/serve.py --port 8129
```

Открыть `http://127.0.0.1:8129/prototypes/pablicus-next/`. Сервер раздаёт только восемь явно перечисленных URL, без каталога репозитория, документов, `.git` и runtime существующего приложения. Модульные импорты требуют HTTP; открытие HTML через file:// не является поддержанным способом запуска.

Проверка (нужны Python Playwright и собственная тестовая Chrome/CDP-сессия):

```sh
python prototypes/pablicus-next/verify.py --cdp http://127.0.0.1:PORT
```

Отчёт: `docs/pablicus/design/2026-09-13-new-foundation/verification/RESULTS.json`. Используется новый контекст без авторизации; браузер пользователя и production не проверяются этим скриптом. Параметры viewport не заменяют физическую iPhone-проверку.

Результат подготовлен для просмотра владельцем. Существующая PWA не обновлялась, финальный дизайн не утверждён. Следующий один цикл описан в SOURCE_RESEARCH.md.
