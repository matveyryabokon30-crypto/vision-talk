## Следующая незавершённая работа

Внутри текущего forensic scope остаётся диагностика точной геометрии и связи сборки/кэша с физическим симптомом. Прежде нового geometry patch необходим measured before FAIL. Предложенный `PABLICUS-BLOCK02-SELECTIVE-RECOVERY-R1` остаётся предложением; его implementation не поручен поздним forensic-заданием. Доказанный flex regression, восстановление профильных функций, media-first actions и deterministic update входят в предложенный recovery-план, но не выполнены.

При будущем разрешении recovery сохранять Controller identity/currentness, Canvas leave guard, durability/outbox, original bytes/IDs/order, resolver cleanup, корректный fullscreen top layer и focus return. Software PASS не снимает physical gate; новое опубликование требует отдельного разрешения. Настоящая фиксация не меняет runtime/tests/workflows и не публикует приложение.
