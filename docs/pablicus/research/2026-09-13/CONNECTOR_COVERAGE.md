## Figma: конкретная граница доступа

Официальный исходный файл SDS не предоставил этому подключению edit access для get_libraries. Аккаунт подтверждён через whoami; платёж или повышение плана не выполнялись. В собственных drafts успешно создан `ppVDFrQo8drbWCyxWtOHj1`, после чего штатный get_libraries и поиск вернули результаты. Это использование доступной функции собственного файла, не изменение прав чужого файла.

Библиотеки: Material 3 Design Kit; Simple Design System; iOS and iPadOS 26; watchOS 26; visionOS 26; macOS 26; iOS and iPadOS 27; macOS 27. Доступных дополнительных библиотек следующей страницы нет. Сервер обработал только первый запрос из batch и явно сообщил, что три остальных не выполнялись; Form Log In, Tabs и Search выполнены последующими отдельными вызовами. Поиск не выдаётся за осмотр каждой вариации всех библиотек.

Источник uiux.build из присланного ролика остаётся неустановленным как редактируемый UI-kit. SDS — отдельно найденный, проверяемый кандидат. Страница Community закрыта для веб-краулера robots.txt; исследование продолжено через официальный GitHub и подключённый Figma. Отсутствие результата не заполнено вымышленным названием конструктора.

## Другие подключённые возможности

Figma, Product Design и Imagegen применимы к последующей работе над оригинальными активами; Remotion и Fal — к сравнению видеопроцесса; OpenAI Developers — к API и агентному исполнению; Supabase — к данным/правам; Documents/PDF — к выдаче материалов. Доступные Canva, Adobe Express, аналитические и коммерческие коннекторы имеют собственные сценарии. Запуск несвязанных покупок, отправок сообщений или генераций не помогает поиску Пабликуса и не является условием полноты исследования.

Подключённый плагин Codex/ChatGPT не становится автоматически плагином внутри Пабликуса. Для продуктового подключения нужен отдельный адаптер, пользовательская авторизация, лицензия, набор разрешённых действий и проверка результата. Эту границу необходимо сохранить при создании каталога «Возможности».
