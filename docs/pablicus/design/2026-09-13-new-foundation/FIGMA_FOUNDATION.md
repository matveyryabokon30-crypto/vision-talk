# Проверенный конструктор и границы поиска

Редактируемая сборка: [Pablicus · конструктор основы / SDS](https://www.figma.com/design/ppVDFrQo8drbWCyxWtOHj1?node-id=4-18). Узел `4:18`, 440 × 542. Это база из экземпляров конструктора; полноценные экраны и Codenotch-панель реализованы в отдельном веб-прототипе и ещё не перенесены в Figma.

| Объект | Подтверждение |
|---|---|
| 4 основных раздела | Связанные Navigation Button instances `4:84`, `4:93`, `4:97`, `4:101` |
| Карточки контекста и помощника | Связанные Card instances `6:270`, `6:337` |
| Основное действие | Связанный Button instance `6:369` |
| Интервал | Импортированная `Space/400`, 16; связана с wrapper padding/itemSpacing |
| Текст | Импортированный Body Base; Inter Regular, 16; шрифты Regular/Semi Bold загружены перед изменениями |
| Фон | Импортированная Background/Default/Default, привязка wrapper fill |

Проверено через инструмент: все семь экземпляров имеют `mainComponent`; последний успешный ответ вернул все ID и снимок всей сборки. На снимке нет видимых обрезаний/пересечений; компоненты не отсоединены. Финальное отдельное чтение всех шрифтов/переменных не состоялось: после сохранения сборки Figma MCP вернула лимит Starter. Результат сохранён, но исчерпывающая повторная проверка API не объявляется выполненной. Покупок/смены тарифа не было.

Перед построением проверено: собственный research-файл был пустым; доступны 8 библиотек, следующей страницы нет. Code Connect ссылки найдены в vendored `figma.config.json`; прямой доступ к официальному файлу ранее возвращал edit-denied. Использованы опубликованные компоненты SDS через search/import. Сервер ограничил batch из трёх поисков первым запросом; оставшиеся Space/400 и Body выполнены отдельно. Ответы и компонентные ключи: [FIGMA_EVIDENCE.json](FIGMA_EVIDENCE.json).

## Именно ролик uiux.build

Редактируемый оригинал «Weekly Smart Basket» **не найден**. Видео показывает дизайн приложения; существование скачиваемого набора компонентов/конструктора из этого конкретного ролика не подтверждено. Подпись предлагает заказать дизайн через сообщение автору, но не показывает название UI kit, файл или лицензию. [Предыдущий осмотр видео](../../research/2026-09-13/FIGMA_VIDEO_REFERENCE.md).

Продолжен публичный поиск по автору, названию приложения, Figma/kit и Figma Community. Прямое открытие Instagram вернуло cache miss; прямое чтение Community ограничено robots.txt. Публичный поиск дал упоминания аккаунта, но не проверенный исходный файл. Поиск доступных библиотек Figma ограничен библиотеками подключённого файла и не доказывает отсутствие непубличного кита. Произвольный домен uiux.build не признан подтверждённым сайтом автора. Исходные 31 референс и продуктовый контекст сохранены отдельно.

Поэтому SDS обозначен как **найденный применимый конструктор**, а не как найденный оригинал ролика. Остающийся блокер точного соответствия видео — отсутствие доступной опубликованной ссылки/файла автора; продолжить Figma API-чтение сейчас дополнительно мешает лимит плана. Сообщения автору без поручения не отправлялись. Независимые части (открытый код, собственная библиотека, сборка SDS, работающая оболочка и браузерные проверки) выполнены независимо от этого пробела.

### Дополнительная проверка через браузер

Публичный [профиль uiux.build](https://www.instagram.com/uiux.build/) удалось прочитать без входа: автор Darpan, услуги дизайна и разработки. В диалоге ссылок две позиции — **Start Your Project** (Google Form) и **Company website** (`www.marknox.com`). Ссылки на Figma-файл там нет. В доступной подписи [свежего ролика](https://www.instagram.com/uiux.build/reel/DdLXTM4NJxG/) снова предложение заказа приложения/SaaS через DM, а не ссылка на kit. HTTPS-сайт компании открылся с `ERR_CERT_COMMON_NAME_INVALID`; проверка сертификата не отключалась. Формы не отправлялись. Это уточняет прежний cache-miss: профиль доступен через браузер, но скачиваемый исходник по просмотренным ссылкам не установлен.
