## 4. Подтверждённые пробелы и причины

1. **Auth:** 1B-T03 исполняет контроллер с искусственным `getSession`, а реальный `sb.auth.onAuthStateChange` проверяет по строкам. В `app.js` 328–338 существует реальный callback с другими ветками и отложенной работой; он не исполняется этим тестом. Причина пробела: неверная граница проверяемой единицы, а не подтверждённая недоступность Auth-сервера.
2. **Отмена выхода с Полотна:** 1B-T04 регистрирует тестовые обработчики экранов и ищет строку `canvasNavigationAllowed()`. Он не вызывает реальную кнопку и её обработчик. Более того, в рабочем пути есть воспроизведённый дефект ниже.
3. **Поздний reject:** 1B-T05 покрывает отказ текущего mount и cleanup, но не позднее отклонение старого Promise после открытия нового экрана. Независимая ограниченная проба текущего контроллера дала PASS. Требуется регрессия в передаваемом наборе; переписывание контроллера без нового отказа не обосновано.
4. **Таймауты:** в тестовом файле есть циклы ожидания флагов, неограниченные Promise и `subprocess.run` без timeout. Запись общего JSON только в конце не гарантирует частичный отчёт при исключении/зависании. Общий CI timeout не закрывает этот пробел.
5. **Передача:** `CONTROLLER_1B_MANIFEST.json` отсутствует в прочитанном `docs/engineering/block-01/` на 3d29127. Прежние IMPLEMENTATION/KNOWN_ISSUES/документы 1A не заменяют манифест окончательного кандидата 1B.

Неполнота результата установлена. Почему Исполнитель прекратил работу именно в этот момент, по одному отчёту не установлено. Отчёт не содержит конкретного технического отказа, препятствующего завершению. Нельзя приписывать остановку отсутствию прав, платформе или мотивации без доказательств.

## 5. Независимое воспроизведение

Среда: Python 3.13.5, Playwright, локальный Chromium. Каждый сценарий ограничен отдельным процессом на 12 секунд; сеть в браузерном контексте заблокирована. Воспроизводимый скрипт: `review_probes.py`; исходные результаты: `1B_PROBE_RESULTS.json`.

Исполнялся точный контроллер и точные тела функций/callers из app.js; DOM и зависимости синтетические. Это не полный авторизованный entrypoint, серверная Auth-проверка или физический iPhone.

| Проба | Результат | Наблюдение |
|---|---|---|
| R1_LATEST_WINS | PASS | При конкурирующих A/B/C открыт только C. |
| R2_LATE_CLEANUP | PASS | Функция и объект dispose вызваны по одному разу, this сохранён, ресурс нового экрана остаётся действующим. |
| R3_LATE_REJECTION | PASS | Новый экран сохранён; поздняя ошибка старого действия зарегистрирована один раз; старые ресурсы освобождены; unhandled rejection не зарегистрирован. |
| R4_UNSAVED_CANVAS_CANCEL | FAIL | При несохранённых изменениях переход с Полотна не вызывает ни hasUnsavedChanges, ни confirm, но вызывает close и меняет экран. |

Точная цепочка дефекта R4: `conversationTab.onclick` (app.js:135) → `navigate` → реальный handler `conversation` (535) → `showConversationView` (121). Handler для уже открытого conversationId вызывает закрытие напрямую; guard из строки 115 отсутствует на этом пути.

Фактические значения R4: до — screen=canvas, canvas=true, visible=true; после — screen=conversation, canvas=false, visible=false; confirm calls=0, unsaved checks=0, close calls=1. Пользовательская отмена даже не запрашивается. Фактическую потерю байтов данных этой пробой не измеряли.

Исправление должно проверять разрешение выхода до разрушения действующего состояния/ресурсов. Возврат прежней вкладки после уже выполненной очистки недостаточен.

## 7. Решение и следующее действие

Промежуточный отчёт в основной части соответствует доказательствам и прямо признаёт незавершённость. Он не является финальной передачей и не содержит ложной приёмки.

**Завершить 1B. Не запускать 1C.** Уже выполненное сохранить; пять пробелов закрыть, навигационный дефект исправить, повторно проверить окончательный кандидат и подготовить передачу. Полный ограниченный промпт: `1B_COMPLETION_PROMPT.txt`.

Пятиблочный план не изменён. 1A не повторяется. Готовность к независимой проверке не равна приёмке. Матвей передаёт промпт Исполнителю; прямого сообщения соседнему чату и фонового запуска этим документом не создаётся.
