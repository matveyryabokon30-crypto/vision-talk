## Решение

Владелец утверждает `AMENDMENT_03_DESIGN_AUTHORITY_AND_ORIGINAL_ASSETS.md` как обязательное основание дальнейшего развития Pablicus совместно с планом 1.0 и Дополнениями 01/02.

## Обязательные решения

1. Платные сторонние шрифты и платные icon packs не являются целевой основой Pablicus.
2. Нелицензированные коммерческие assets не используются даже как временная runtime-зависимость.
3. Для прототипов допускаются системные либо бесплатные/open-source substitutes с подходящей лицензией.
4. Pablicus получает собственную оригинальную icon system.
5. Pablicus получает собственную типографическую идентичность; до готовности собственного целевого актива применяется квалифицированный interim font.
6. Референсы RonDesignLab и других студий используются для изучения принципов visual/motion/interaction language, а не для копирования конкретных assets или интерфейсов.
7. Создаётся отдельный рабочий контур / чат Codex **«Главный дизайнер проекта»**.
8. Главный дизайнер проектирует весь Pablicus и полную дизайн-систему под руководством владельца до массового внедрения нового визуального слоя в код.
9. После owner approval дизайн передаётся Исполнителю для внедрения в разрешённых инженерных границах.
10. Проверяющий независимо проверяет реализацию относительно утверждённого Pablicus design source of truth.

## Неизменяемые границы

- Pablicus остаётся одной системой.
- Пять инженерных блоков `1 → 2 → 3 → 4 → 5` сохраняются.
- Отдельный Block 6 не создаётся.
- Plan 1.0 + Amendments 01/02 сохраняются.
- Базовые вкладки `Чаты / Дела / Вы` сохраняются до отдельного решения владельца.
- Принятая архитектура 2A не переоткрывается настоящим решением.
- Текущий подтверждённый статус: `SUBSTEP_2A_ACCEPTED`; Block 2 целиком не принят.
- 2B не начинается автоматически: требуется отдельное задание владельца.
- Настоящее решение не разрешает production deployment, массовый runtime redesign, обход gates или покупку платных визуальных зависимостей.
